# 🔧 Task 25 — حذف دانلود مستقیم پکیج + پاسخ مدیر به دیدگاه‌ها + فوتر + تست‌سوییته کامل

## ۱) حذف دانلود مستقیم پکیج برای مشتری

**تصمیم محصول:** مشتری نباید بتواند فایل پکیج را مستقیم دانلود کند؛ نصب فقط با
«کد آپدیت» داخل فروشگاه‌ساز/افزونه او انجام می‌شود (جریان API آپدیت‌سنتر).

تغییرات:
- ❌ حذف دکمه «دانلود» از پروفایل مشتری (`customer-profile.blade.php`) — به‌جای آن جعبه
  راهنمای سبز: «دانلود مستقیم ممکن نیست؛ کد آپدیت را در فروشگاه‌ساز خود وارد کنید»
  (کد آپدیت مشتری داخل متن نمایش داده می‌شود)
- ❌ حذف مسیر `GET /customer/download/{license}` و کنترلر
  `CustomerPackageDownloadController` به‌طور کامل
- ✏️ متن‌های گمراه‌کننده «از صفحه پکیج‌ها دانلود کنید» در `payment-result` به
  «کد آپدیت را در فروشگاه‌ساز وارد کنید» تغییر کرد
- ℹ️ دانلود محصول (پروژه) دست‌نخورده ماند — آن خرید «دانلود فوری» است و ماهیتش فرق دارد

## ۲) پاسخ مدیر به دیدگاه‌ها

- 🆕 مایگریشن `2026_10_17_000003_add_reply_to_comments_table`:
  `comments.reply` (text nullable) + `comments.replied_at` (timestamp nullable)
- مدل `Comment`: `saveReply()` / `removeReply()` / `hasReply()` + fillable/casts
- ادمین `/admin/comments`: دکمه پاسخ (آیکون `corner-up-left` 🆕 در رجیستری آیکون) +
  مودال با پیش‌نمایش دیدگاه + پیش‌پر شدن پاسخ فعلی + ویرایش/حذف پاسخ
- فروشگاه (`CommentSection` در صفحه پکیج و محصول): جعبه «پاسخ مدیر» با رنگ برند
  زیر دیدگاه‌های **تأییدشده** (دیدگاه pending/rejected هرگز نمایش داده نمی‌شود)

### 🐛 باگ‌هایی که تست‌ها در همین مرحله پیدا و رفع کردند

1. **خرید رایگان محصول `sales_count` را افزایش نمی‌داد** — مسیر رایگان از `markAsPaid`
   عبور نمی‌کرد؛ حالا `incrementSales()` دستی بعد از create.
2. **کد تخفیف تکراری با حروف کوچک/بزرگ** — نرمال‌سازی بعد از validate انجام می‌شد و
   `welcome10` از unique رد می‌شد ولی بعداً UNIQUE constraint دیتابیس می‌داد؛ حالا کد
   **قبل از validate** نرمال می‌شود.
3. **`PackagePricingPlan::final_price` با `discount_price = 0` طرح را رایگان می‌کرد** —
   `discount_price ?? price` برای صفر هم صفر برمی‌گرداند (صفر ≠ null). حالا فقط تخفیفِ
   معتبر (>۰ و < قیمت) اعمال می‌شود. (ادمین برای بدون‌تخفیف null ذخیره می‌کند)
