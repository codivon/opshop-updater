# Task 35 — تکمیل بخش قالب‌ها (Templates v2) + گزارش‌های بازه‌ای

تاریخ: ۲۰۲۶-۱۰-۲۲ — شاخه: master (و feature/product-marketplace)

## ✅ خلاصه تغییرات (۱۵ درخواست کاربر)

### ۱) صفحه اصلی
- بخش «قالب‌های آماده» در صفحه اصلی فروشگاه فعال است (کارتهای قالب + آمار).
- قالب‌های واگذارشده (خرید اختصاصی موفق) دیگر در صفحه اصلی و فروشگاه نمایش داده نمی‌شوند.

### ۲) رفع باگ «تصویر قالب تغییر نمی‌کند»
- ریشه ۱: بعد از ذخیره، فایل آپلودی از state پاک نمی‌شد و با input قدیمی `wire:ignore` تداخل داشت.
- ریشه ۲: URL تصویر بدون بررسی واقعی فایل ساخته می‌شد (۴۰۴ بی‌صدا).
- رفع:
  - پاک‌سازی کامل `$thumbnailFile` بعد از ذخیره + `thumbNonce` در `wire:key` برای رندر مجدد input.
  - helper جدید `template_asset_url()` در `bootstrap/helpers.php` (public → fallback storage با کش‌بریک → تصویر پیش‌فرض).
  - صفحه «جزئیات قالب» حالا دکمه «ویرایش قالب» با مودال کامل دارد (مثل پکیج‌ها) — تصویر شاخص + گالری + همه فیلدها.

### ۳) قیمت‌گذاری دوگانه (خرید معمولی + خرید اختصاصی)
- ستون‌های جدید روی `templates`: `exclusive_price`، `exclusive_discount`، `exclusive_note`، `is_sold_exclusively`، `sold_exclusively_at`.
- مدل: `Template::finalPriceFor(type)`، `exclusive_final_price`، `has_exclusive_offer`.
- فروشگاه: انتخابگر رادیویی «خرید معمولی / خرید اختصاصی» با توضیح و قیمت هرکدام + کد تخفیف برای هر دو.
- پس از نخستین خرید اختصاصی موفق: قالب از فروشگاه/خانه/API حذف می‌شود و صفحه‌اش پیام «واگذارشده» می‌دهد.
- فیلد تخفیف (٪) جداگانه برای هر دو نوع قیمت.
- API: پارامتر `purchase_type=normal|exclusive` در `POST /api/v1/templates/{slug}/purchase` با همان گاردها.

### ۴) کدهای تخفیف
- فروشگاه قالب: کامل هماهنگ (apply/remove + راستی‌آزمایی سمت سرور + مصرف شمارنده در تأیید پرداخت).
- API قالب‌ها: عیناً مثل API پکیج‌ها — بدون کد تخفیف (همان محدودیت).
- تغییر نوع خرید → کد اعمال‌شده ریست می‌شود (مبلغ مبنا عوض می‌شود).

### ۵) لایسنس
- جدول جدید `template_licenses` + مدل `TemplateLicense` (کلید `TMP-XXXX-XXXX-XXXX-XXXX`، دائمی).
- صدور خودکار پس از هر پرداخت موفق (`TemplatePurchase::markAsPaid` → `TemplateLicense::issueFor` — idempotent).
- نمایش کلید در صفحه نتیجه پرداخت قالب + تب «لایسنس‌ها» در جزئیات قالب + تب دوم صفحه «لایسنس‌ها» پنل (باطل/فعال‌سازی/حذف).
- **لایسنس‌ها جزو گزارش‌ها شدند** (کارت آماری در نمای کلی + کارت «لایسنس‌های صادرشده» در تب فروش).

### ۶) گالری
- جدول جدید `template_images` + مدل `TemplateImage` (عیناً مثل پکیج‌ها).
- تب «گالری» در جزئیات قالب: آپلود چندتایی، ترتیب با فلش‌ها، حذف با مودال.
- نمایش گالری با لایت‌باکس در صفحه فروشگاه قالب + آپلود گالری در مودال ویرایش.

### ۷) داشبورد مدیر
- کارت‌های آمار: محصولات + قالب‌ها اضافه شد (کنار پکیج‌ها و…).
- کارت درآمد کل: حالا ۴ جزء (اشتراک‌ها/پکیج‌ها/محصولات/قالب‌ها).
- نمودار سوم «فروش قالب‌ها (۶ ماه اخیر)».
- سکشن جدید «فروش قالب‌ها»: ۴ آمار کوچک + آخرین فروش قالب‌ها + پرفروش‌ترین قالب‌ها.

### ۸) گزارش‌ها — بازطراحی کامل تب «فروش»
- فیلتر بازه: روزانه / هفتگی / ماهانه / سالانه / همه / بازه شمسی دلخواه (۱۴۰۴/۰۷/۰۱ یا 2025-09-23).
- KPI بازه: درآمد بازه، تعداد سفارش، میانگین هر سفارش، رشد نسبت به دوره قبل (٪).
- نمودار فروش بازه: روزانه (≤۳۱ روز) یا ماهانه (بازه‌های بلندتر) با برچسب شمسی.
- **فروش جزءبه‌جزء همه بخش‌ها** در یک جدول یکپارچه: پکیج + محصول + قالب + اشتراک (خریدار، نوع، مبلغ، تخفیف، کد تخفیف، درگاه، تاریخ) با صفحه‌بندی.
- تفکیک بر اساس نوع فروش + تفکیک درگاه‌های پرداخت + آمار کدهای تخفیف (تعداد و مجموع تخفیف).
- درآمد کل (همه زمان‌ها) با تفکیک ۴ بخش.
- پرفروش‌ها: پکیج‌ها / محصولات / قالب‌ها (سه کارت کنار هم).
- **خروجی CSV** با UTF-8 BOM (سازگار با اکسل) از فروش‌های بازه فعلی.
- نمای کلی + خلاصه‌ها: کارت‌های قالب‌ها/محصولات/لایسنس‌ها اضافه شد؛ درآمد کل حالا ۴ جزء دارد.

### ۹) دسته‌بندی‌های پیش‌فرض قالب‌ها
- مایگریشن `2026_10_22_000005` (idempotent): قالب وب‌سایت (شرکتی/فروشگاهی/وبلاگ/خبری/شخصی)، لندینگ‌پیج، پنل و داشبورد، HTML و UI کیت، سایر قالب‌ها.
- همان درخت در `CategorySeeder::seedTemplates()` هم هست (`php artisan db:seed --class=CategorySeeder`).

### ۱۰) نوار پیشرفت آپلود (همه‌جا)
- کامپوننت جدید `<x-upload-progress target="…" label="…"/>` (Alpine + رویدادهای Livewire 3) — درصد زنده + نوار.
- نصب روی: تصویر شاخص و گالری قالب (index/show)، فایل ZIP نسخه قالب، ۴ ورودی پکیج (شاخص/گالری/نسخه/تصاویر)، محصول (شاخص + نسخه)، فایل پشتیبان، لوگوی درگاه‌ها.

### ۱۱) پیشنهادهای تکمیلی خودمان (اعمال شد)
- رشد نسبت به دوره قبل (٪) + مبلغ دوره قبل در hint.
- تفکیک درگاه‌های پرداخت بر اساس درآمد.
- آمار مصرف کدهای تخفیف.
- میانگین مبلغ سفارش.
- خروجی CSV.
- کارت لایسنس‌ها (پکیج + قالب) در گزارش‌ها.
- سکشن اختصاصی قالب‌ها در داشبورد.
