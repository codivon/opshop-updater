# آپدیت‌سنتر — پنل مدیریت پروژه‌ها، پکیج‌ها، محصولات و لایسنس‌ها

پنل مدیریت مدرن بر پایه **Laravel 13 + Livewire 3** با تجربه SPA (بدون ریلود صفحه)، طراحی بازنویسی‌شده با **Tailwind CSS 4**، RTL کامل و فونت وزیرمتن.

## امکانات

- **داشبورد**: آمار زنده، چارت‌های SVG سبک، آخرین خریدها/آپدیت‌ها، لایسنس‌های در حال انقضا
- **پروژه‌ها / آپدیت‌ها**: CRUD کامل با مودال + آپلود فایل ZIP
- **پکیج‌ها**: کارت‌گرید، صفحه جزئیات با تب‌های (اطلاعات / نسخه‌ها / پلن‌های قیمت / لایسنس‌ها / گالری) + فیلتر دسته‌بندی ساختاریافته
- **محصولات (پروژه‌های قابل‌فروش)**: فروش مستقیم اسکریپت/قالب/اپلیکیشن با خرید مهمان بدون ثبت‌نام — صفحه تکی با دیدگاه‌ها (تأیید مدیر)، نسخه‌بندی + changelog، دانلود ZIP توکنی یک‌بارمصرف ۱۵ دقیقه‌ای و پیگیری خرید با شماره تراکنش
- **دسته‌بندی‌ها**: جدول مشترک برای محصولات و پکیج‌ها (قابل مدیریت از پنل) + فیلتر دسته/قیمت/جستجو/مرتب‌سازی در هر دو بخش فروشگاه
- **دیدگاه‌ها**: ثبت مهمان روی صفحه محصول → تأیید/رد/حذف از پنل (با نشان تعداد در انتظار در منو)
- **نسخه‌های پکیج/محصول**: آپلود ZIP + هش SHA256 + محدودیت نسخه/PHP/Laravel + وابستگی‌های JSON
- **لایسنس‌ها**: صدور خودکار، ابطال/فعال‌سازی، منقضی‌کردن قدیمی‌ها، تاریخچه توکن دانلود
- **خریدها**: تراکنش‌ها + وضعیت پرداخت + خلاصه درآمد
- **مشتریان / اشتراک‌ها**: CRUD + تمدید اشتراک + کد آپدیت با دکمه کپی
- **گزارش‌ها**: ۴ تب تحلیلی (نمای کلی / مشتریان / آپدیت‌ها / فروش) با فیلتر تاریخ
- **لاگ‌ها**: نمایش ترمینالی با سطح ERROR/WARNING/INFO + دانلود + پاک‌سازی
- **تنظیمات + درگاه‌ها**: تنظیمات عمومی/ایمیل + پیکربندی ۱۱ درگاه پرداخت ایرانی
- **API عمومی مشتریان** (`routes/api/v1.php`): بدون تغییر باقی مانده — چک آپدیت، خرید، لایسنس، دانلود توکنی

## ویژگی‌های فنی

- `wire:navigate` برای ناوبری SPA + نوار پیشرفت + انیمیشن‌گذار صفحات
- دارک‌مود (کلاس `dark` + ذخیره در localStorage) بدون فلش اولیه
- سایدبار جمع‌شونده + دراور موبایل
- توست‌های سراسری با `WithToasts` trait (رویداد Livewire → Alpine Store)
- صفحه‌بندی RTL فارسی (اورراید `livewire::tailwind`)
- آیکون‌های Lucide به‌صورت inline (بدون وابستگی)
- تاریخ شمسی با morilog/jalali + اعداد فارسی
- مودال‌های Livewire (entangle) برای همه فرم‌ها

## نصب

```bash
composer install
cp .env.example .env      # سپس APP_KEY و DB را تنظیم کنید
php artisan key:generate
touch database/database.sqlite   # اگر از sqlite استفاده می‌کنید
php artisan migrate
php artisan storage:link

npm install && npm run build     # یا bun
php artisan serve
```

> داده نمونه برای تست: `php demo-seed.php`

## ساختار

```
app/Livewire/            کامپوننت‌های صفحه (Dashboard، Projects/، Packages/، ...)
app/Livewire/Concerns/   WithToasts
app/Services/            سرویس‌های اصلی (تصاویر، لایسنس، پرداخت)
app/View/Components/     رجیستری آیکون‌های SVG
resources/views/components/   کامپوننت‌های UI (btn, input, modal, tabs, chart, ...)
resources/views/livewire/    ویوهای صفحات
routes/api/v1.php        API عمومی (دست‌نخورده)
```

## نکته‌ها

- آپلود فایل موقت Livewire به‌صورت پیش‌فرض به ۱۲MB محدود است (قابل تغییر در `config/livewire.php`).
- API کلاینت‌ها (سیستم‌های مشتری) تغییری نکرده و همان `api/v1/*` قبلی است.
